# Shared and Weak

# Описание:

# Реализовать shared\_ptr and weak\_ptr

# 

# Что реализовано:

# shared\_ptr, weak\_ptr, counter, lock, expired, copy/move, разрыв циклов через weak\_ptr

# 

# Ограничения:

# Безпотокобезопасности, без кастомных deleter, без make\_shared

# 

# Требования:

# C++17, MSVC

# 

# Сборка и запуск:

# Developer command prompt

# 

# cd путь к файлам(C:\\...\\...)

# 

# cl /EHsc /std:c++17 Source.cpp /Fe:program.exe

# 

# запуск program.exe
